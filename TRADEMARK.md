# Trademark and Branding Guidelines

## Project Name

"Open Source Photo Gallery" is the official project name. You may refer to it as such in your own work.

## Trademarks

The following names and logos are **not** owned or controlled by this project:
- PowerMedia
- Any photography studio or race series names
- Motorsport or sports-related trademarks

## What You Can Do

✅ **Permitted**

1. **Use the software** — Run it for your own business
2. **Modify the code** — Make changes for your needs
3. **Distribute modified versions** — Share your improvements under AGPL-3.0
4. **Reference the project** — "Powered by Open Source Photo Gallery" is fine
5. **Fork and rebrand** — Create your own distribution under a different name

## What You Cannot Do

❌ **Not Permitted**

1. **Claim original authorship** — You must retain original author attribution
2. **Trademark the code** — You cannot trademark "Open Source Photo Gallery" or similar variations
3. **Remove AGPL compliance** — The AGPL-3.0 license must be preserved
4. **Sell the source code** — You can sell services (hosting, customization) but not the code itself
5. **Remove attribution** — Credit to original authors must remain in code and docs

## Rebranding Your Fork

If you fork and significantly modify this project, you should:

1. Rename it to something unique (e.g., "MyStudio Photo Galley")
2. Keep original license and attribution
3. Update README to clearly state it's a fork/modified version
4. Update CHANGELOG to document your modifications
5. Consider version numbering that reflects the fork (e.g., 2.0-mystudio-1)

Example attribution:

```markdown
# MyStudio Photo Gallery

A customized version of [Open Source Photo Gallery](https://github.com/...).

Modifications include: [list your changes]

Original project authored by: [original author]
Current maintainer: Your Name/Company

Licensed under AGPL-3.0 (see LICENSE)
```

## Open Source Collaboration

We encourage you to:
- **Contribute improvements** upstream (create pull requests)
- **Share bug fixes** with the community
- **Discuss design decisions** in GitHub Issues before forking
- **Report security issues** responsibly

If your fork adds significant features, consider contributing them back to the main project so everyone benefits.

## Questions?

If you have questions about trademark usage or licensing, open a GitHub issue or contact the project maintainers.

---

**TL;DR:** Use the software freely, modify it, distribute your versions under AGPL-3.0, but give credit to the original authors.
